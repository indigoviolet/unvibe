vibe to code. unvibe to understand.

Unvibe reads a branch or pull request with you, using your Claude Code or Codex subscription.

npm install -g github:indigoviolet/unvibe#release
unvibe setup
unvibe open

Needs macOS or Linux with Node 24+, git, gh, and the claude or codex CLI (d2 optional for diagrams).

Start with the story

Open a PR or branch and get a guide that restates the change as linked pages: the idea first, then the decisions and alternatives, each tied to the exact lines.

Keep asking why

Select any phrase to explain it or ask a follow-up. Answers land anchored to the text and build on earlier pages instead of starting over.

Untangle the plotlines

Follow concepts, data flow and findings across cards and diagrams, with depth controls and a second opinion when a claim needs pressure-testing.

Review in your own voice

Leave notes anywhere, collect them in the Outbox, and submit once as a single GitHub review — or copy them as Markdown on any review.

Use the subscriptions you have

Unvibe drives your own Claude Code and Codex logins through their CLIs. No new account, no separate API billing to set up.

Local, no middleman

The service runs on your machine and talks only to loopback. Your reviews stay on your disk, and nothing reaches GitHub until you submit.

Unvibe is a local reader for code changes. Source and open work: github.com/indigoviolet/unvibe.
